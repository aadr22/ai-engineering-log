## Mon Sep 28: NumPy vectorization

### What I learned
- Python loops are slow because every element is a full Python object
  with type lookups and new objects per step; NumPy runs one compiled
  loop over raw contiguous memory (plus SIMD)
- `shape` matters: (3,), (1, 3) and (3, 1) behave differently
- `axis` = the dimension that disappears; `keepdims=True` keeps it as size 1
- Broadcasting: compare shapes from the right; dims match if equal or 1
- Boolean masks replace loop + if; `np.maximum(a, 0)` is ReLU
- Use `np.allclose`, not `==`, to compare float results

### What I built
- Vectorized sum of squares, column z-score, negative clipping,
  and pairwise distances with 3-D broadcasting
- Speedups: Ex1 __x, Ex2 __x, Ex3 __x

### What confused me
- Pandas `.std()` uses n−1 but NumPy `np.std` uses n (ddof)
